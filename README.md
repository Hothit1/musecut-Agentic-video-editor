# MuseCut — Agentic Video Editor

**Long video → editable Edit Plan → approved 9:16 short.**
Upload a long talking-head video and a prompt. MuseCut drafts an Edit Plan with Meta models;
you edit it (segments, captions, B-roll, thumbnail, music, 60/90 s) and only after **Approve**
does it render the final vertical MP4. Nothing is rendered from an unapproved plan.

Meta Global AI Developer Hackathon 2026 · Startup track · theme *Build for Your World*.

## Meta models, step by step

| Step | Model (Meta Model API) | What it does |
|---|---|---|
| Transcribe | `muse-voice-transcribe-1.0` (`/v1/asr/transcribe`) | Audio is split at silences into 2–15 s phrases; each phrase is transcribed → phrase-level timestamps |
| Edit Plan | `muse-spark-1.3` (Responses API, JSON schema output) | Picks hook → main → closing segments by **phrase id** (never invents timestamps), reasons, scores, title, hook, post copy, hashtags, chapters |
| Reframe 9:16 | `sam-3.1` **video mode** (concept `"face"`, 5 fps proxy clip, 1 request per segment) | Stable object ids follow the speaker through the clip → crop path with EMA smoothing + pan speed limit; face must stay fully inside the crop. ~5× cheaper than per-image calls; per-image mode kept as fallback |
| Thumbnails + B-roll | `muse-image-1.0` (`/images/edits`, `/images/generations`) | 3 thumbnail options from the best face frame + title; illustrative B-roll stills (Ken Burns) |
| Render | FFmpeg (not a model) | Cuts, pause shortening, reframe, B-roll, burned-in captions, ducked music |

Every model call is written to a cost log (model, step, input/output summary, tokens/frames,
estimated USD, status, latency) and exported with the result.

**Honest limits.** Muse Voice Transcribe returns turn-level times, not per-word times. Word
highlight timing inside a phrase is *estimated* (proportional to word length). Filler words
("uh", "um", stutters) are removed from captions; audio is cut only at phrase boundaries, so a
filler inside a phrase stays audible. Pauses > 0.25 s between phrases are cut, voice is never sped up.

## Run it

Requirements: macOS/Linux, Python 3.12, FFmpeg with libx264 (`brew install ffmpeg`).

```bash
cd musecut
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env          # put your Model API key in META_API_KEY (never commit .env)
.venv/bin/python assets/music/make_music.py     # (re)generate the CC0 music track
.venv/bin/uvicorn backend.app:app --port 8765
open http://127.0.0.1:8765/
```

Tests: `.venv/bin/python -m pytest -q tests`

## API

```
POST   /api/projects              multipart: video, prompt, target_duration_sec(60|90) -> project_id
POST   /api/projects/{id}/plan    start plan job (transcribe -> Spark -> SAM -> Muse Image)
GET    /api/projects/{id}/plan    plan + job status + crop tracks
PATCH  /api/projects/{id}/plan    edit segments/captions(text only)/title/hook/post/thumbnail/music/target
POST   /api/projects/{id}/approve lock plan, start render job (409 on later PATCH)
GET    /api/projects/{id}/render  queued | processing | done | failed
GET    /api/projects/{id}/export  MP4, SRT, thumbnail PNG, plan JSON, cost log, post copy
```

The plan is validated against [`schema/edit-plan.schema.json`](schema/edit-plan.schema.json)
plus semantic checks on every save. Spark output that fails validation is sent back to Spark
with the errors (max 3 attempts), then the job fails with a clear message. No guessing.

## Not in v1 (roadmap)

Lip-sync, dubbing to other languages, many shorts from one video, multi-speaker diarization,
AI-generated music, stock-footage B-roll. One great short beats many half-done features.
